# Iron Age Furniture Oh The Biomes Add-On

Adds matching Iron Age Furniture designs for the wood families from Oh The Biomes You'll Go and, on supported newer Minecraft versions, Oh The Biomes We've Gone.

This repository contains loader- and Minecraft-version-specific branches. The initial `master-1.12` branch supports Forge 1.12.2 with Oh The Biomes You'll Go.
